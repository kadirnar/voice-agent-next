Talk to a voice agent over a WebSocket (van-ws/1). Use headphones or a browser with good echo cancellation (Chrome, Edge, Safari).

How it works

The microphone is captured with getUserMedia (echo cancellation, noise suppression and auto gain on), resampled to 16 kHz in an AudioWorklet and sent as 20 ms binary frames of PCM16. Agent audio arrives as 24 kHz PCM16 binary frames and is played by a second AudioWorklet, which reports its playback position back to the server (playback) so the agent knows what you actually heard. On clear (you interrupted the agent) queued audio is dropped at once. Transcripts, agent state and latency metrics arrive as JSON messages.
